# File Structure
All text files are stored in the `texts/` folder, organized by category:
- `sys/`: UI texts, buttons, prompts.
- `dia/`: Character dialogues (organized by chapter).
- `doc/`: In-game documents (FO/HF introductions, error logs, etc.)
- `item/`: Item names and descriptions.
- `oth`: Other texts and descriptions.

---

# Translation Notes
1. Use a plain text editor (e.g., Notepad, VS Code) and disable "word wrap".
2. **NEVER change the line count of any file.** If you need to insert or delete content, make sure the total number of lines stays the same (you can use empty lines as placeholders).
3. If you see placeholders like `{player_name}`, keep them as-is – do NOT translate them.

---

# Notes
- Keep an eye on the line number displayed at the bottom of your editor. If it changes, press Ctrl+Z to rollback to the latest correct version.
- Save the file with the same encoding as the original.
